# Task Specifications

Specifications for individual changes will be added here once their requirements are known. There are no specifications yet.

[PRODUCT_SPEC.md](../docs/requirements/PRODUCT_SPEC.md) describes the general requirements. A task specification clarifies a specific scope of work and refers to the requirements without creating a second, independent copy of them.

For a non-trivial task, it is enough to describe the goal, boundaries, related requirements, expected behavior, acceptance criteria, verification method, and open questions. Mark the status as draft / ready for implementation / implemented / cancelled. Confirm implementation with links to changes and verification results.

A separate document is not required for a small, obvious change. Do not create empty specifications in advance.
